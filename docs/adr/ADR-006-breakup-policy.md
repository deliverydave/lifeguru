# ADR-006: Breakup / leave relationship policy

- Status: Accepted
- Date: 2026-09-07

## Decision

Private data stays with each owner. Shared explicit artifacts freeze read-only for remaining partner for 30 days, then delete unless copied into private notes. Abstracts from leaver revoke immediately. Joint goals freeze then archive.

## Consequences

- UX copy must be honest about irreversible past influence
- Leave workers enforce revoke + freeze
- See copy/leave-relationship.md
